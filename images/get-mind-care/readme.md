# /public/images/get-mind-care/

Place this client's real project imagery here as:

    cover.jpg

Recommended specs:
- Aspect ratio: 4:3 (used in the work grid) — a 16:8 crop is also
  auto-applied at the top of the case study page, so choose an image
  with a clear focal point that still reads well when cropped wider.
- Minimum width: 1600px
- Format: JPG or WebP, optimized for web (under ~400KB)

Until a real asset is added, the site shows a tasteful text-based
placeholder automatically -- no stock or placeholder photography is
downloaded from the internet. Simply drop cover.jpg in this folder
to replace it; no code changes are required.

Additional product/lifestyle images for this case study can also be
added to this folder and referenced manually inside
src/pages/CaseStudy.jsx if you want a richer gallery later.
