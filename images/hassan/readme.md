# /public/images/hassan/

Place Hassan Junaid's real portrait here as:

    hassan.jpg

Recommended specs:
- Aspect ratio: 4:5 (portrait)
- Minimum width: 1200px
- Format: JPG or WebP, optimized for web (under ~300KB)

Until a real photo is added, the Founder section shows an elegant
dark-green placeholder with "HJ" — no fake or AI-generated person is
used. The placeholder is handled automatically in
`src/components/FounderSection.jsx` via an image `onError` fallback,
so simply dropping `hassan.jpg` in this folder is enough to replace it.
